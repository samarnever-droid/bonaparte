# Color Grade
A neutral-by-default, 12-control grading filter. Input/output: straight-alpha RGBA8 sRGB. Exposure and relative white balance are evaluated in linear RGB; tone, gamma and color controls operate on the display-referred result. Alpha is preserved exactly. Not an ACES/HDR pipeline, Kelvin camera model, or LUT processor. Parameter bounds, defaults, grouping and steps are defined once in `manifest.toml` and shared by the UI, host and MCP. The native GPU preview host executes the WGSL and is tested against CPU output. Exports remain on the full-resolution CPU reference.
